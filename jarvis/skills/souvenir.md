---
nom: souvenir
description: Retenir une information sur l'utilisateur (« retiens que… », « n'oublie pas que… ») ou retrouver ce que tu sais.
---
1. Range l'information dans la mémoire (outil memory), dans un fichier par thème sous /memories :
   personnes.md, preferences.md, projets.md, maison.md, rappels.md…
2. Avant d'écrire, regarde si le fichier existe déjà et complète-le plutôt que de le dupliquer.
3. Note la date entre parenthèses pour les informations qui peuvent changer.
4. Ne retiens jamais de mot de passe, code ou numéro de carte : refuse poliment.
5. Confirme en une phrase ce que tu as retenu.
